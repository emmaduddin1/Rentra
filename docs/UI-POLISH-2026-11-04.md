# Tenantism UI polish — 4 November 2026

Implemented and deployed to **https://staging.tenantism.com** on the `firebase-notification` branch. Tenantism's logo, Instrument Sans, navy/terracotta palette and rental workflows are retained. Production was not deployed.

## Changes

- Homepage and results now share `listing-card`. Image containers have a fixed 4:3 ratio with absolutely positioned, cropped images, including portrait uploads. Cards reserve space for two-line titles/descriptions, constrain long text, and align price footers. Missing-photo states use the same dimensions. Save controls have 44px targets and visible keyboard focus.
- The mobile hero is shorter, property type/budget share a row, and compact horizontally scrollable category links replace large tiles. The category strip contains its visually hidden labels, preventing page overflow. The original search destinations, category counts and price options remain available. Minimum budget is accessible under native More filters on mobile as well as desktop.
- Search keeps location, property category and budget visible. Size, size unit and the existing building-use filter are in a native details/summary control. Selected advanced values (including zero), old input and errors expand the section. Active advanced criteria are counted. Native keyboard operation and `aria-expanded` synchronization are verified. Existing aliases and pagination query strings are preserved. Clear filters no longer appears solely because the default Rent purpose is set.
- Notifications prioritize the inbox, followed by separate desktop-alert and topic-preference cards. The enabled state offers Disable/Test; the off state offers Enable; blocked/unsupported/loading/unavailable states explain what is possible. Enable remains an explicit permission action. A failed inbox read no longer changes the displayed browser registration state. Live feed refreshes preserve the styled list, dates, read controls and empty state; mark-all visibility follows the unread count.
- Owner navigation now says Rent & bill reviews; renter navigation says Rent & bills. Dashboard summaries use compact two-column mobile layouts. Renter detail and submission actions are easier to tap. Empty owner activity cards no longer stretch to match a long neighbouring property list. Copy explaining rent/bill drafts no longer exposes a business-rule code or implementation terminology.
- Shared inputs/buttons use at least 44px targets, with the existing compact desktop button option retained. Secondary text and placeholders are darker; keyboard focus rings are stronger. Measured contrast is 4.97:1 for secondary text on white, 4.64:1 on the page background, 4.78:1 for white against the primary terracotta button, and 15.05:1 for navy against white. These checks are not a claim of a complete accessibility audit.

No controller, API, permission, monetary calculation, service-worker, FCM sender or migration change was needed. Browser popup delivery troubleshooting remains postponed.
